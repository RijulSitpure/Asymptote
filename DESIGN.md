# Design System: Asymptote

## Philosophy & Core Principles

Asymptote is an algorithmic pattern intelligence platform designed for engineers who value disciplined cognition over mindless code grinding. The interface uses a clean, light-first palette built on Slate `#1e2033`, Emerald `#10b981`, and a 32px checked drafting grid `#e6ebf1` on `#f6f8fa`.

### Core Rules
1. **Light Theme Only**: All dark surfaces are eliminated.
2. **Zero Shadows**: Clean separation is achieved purely via 1px `#e2e8f0` borders.
3. **No Orange**: Amber `#f59e0b` is reserved strictly for hint triggers.
4. **Typography**: Space Grotesk 500/700 for headings, wordmark, and stat numbers; DM Sans 400/500/700 for body and controls; system monospace for code.
5. **Checked Background**: 32px square grid on main content and extension body.
